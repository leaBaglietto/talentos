# Assets - Logos de la Agencia

Guardá en esta carpeta los logos que quieras importar directamente en tus componentes de React utilizando la sintaxis de importación de Vite.

## Cómo usarlos en el código:

**En tus componentes de React:**
```tsx
import logoUrl from '@/assets/logos/logo.svg';

// Luego en el JSX:
<img src={logoUrl} alt="Logo de la Agencia" className="h-12 w-auto" />
```
